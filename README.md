## Learning Management System (LMS)

Full-stack production-ready LMS with Student, Teacher, and Admin roles, built with:

- **Frontend**: React + TailwindCSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **Auth**: JWT, OTP, email verification, forgot password via OTP
- **Storage**: Cloudinary for videos/images
- **Payments**: Razorpay
- **Email**: Nodemailer

This project is structured for deployment on platforms like Render / AWS / Azure.

The codebase is generated step-by-step; see backend and frontend READMEs for setup details.
